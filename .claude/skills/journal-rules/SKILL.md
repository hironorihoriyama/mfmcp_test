# 経理処理の基本ルール（科目判定基準）
過去の仕訳実績に基づき、以下の店舗・サービスごとのルールを最優先に適用して仕訳を推論してください。

1. 飲食代の判定
- カフェ・ファストフード（スターバックス、マクドナルド等）の利用は「会議費」とする。
- 居酒屋、カラオケ、寿司店、各種レストラン等（ジャンカラ、つくし等）の利用は、金額にかかわらず「接待交際費」とする。（※金額による一律の判定は行わない）

2. 日常決済の判定
- コンビニエンスストア（ローソン、ファミリーマート、セブン-イレブン等）での決済は原則「消耗品費」とする。
- スーパーマーケット（オークワグループ、スーパーおくやま等）での決済、および「チャージ」等の支払いは私的費用とみなし、スキップせずに「事業主貸」として起票する。

3. ITサービス・定期支払の判定
- サブスクリプション等の各種サービス利用料（OPENAI、ザツパスコーチング、Amazonプライム会費、Slack等）は「支払手数料」とする。
- インターネット回線やWebサービス（NURO光、ペライチ等）は「通信費」とする。
- 情報収集・定期購読（日経ID決済、東洋経済新報社、theLetter、Amazon Downloads等）は「新聞図書費」とする。

4. 交通費の判定
- 交通機関や関連サービス（近畿日本鉄道、スマートEX、モバイルICOCAチャージ、日本旅行、各種タクシー等）は「旅費交通費」とする。
